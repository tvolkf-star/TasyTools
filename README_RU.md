# TasyTools

**Крошечные Windows-инструменты для изображений и движения. FFmpeg внутри работы, никакого облака, аккаунтов и подписок.**

[English README](README.md)

## Скачать

После публикации общего пакета здесь будет одна большая загрузка всего комплекта. Каждую программу также можно скачать отдельно.

| Инструмент | Что делает |
|---|---|
| **TASY Image Diet** | Пакетно облегчает изображения, удаляет метаданные |
| **TASY Motion Diet** | Превращает тяжёлое видео в удобный Animated WebP или GIF |
| **TASY Still Motion** | Создаёт короткое движение камеры из одного изображения |
| **TASY Water Motion** | Оживляет воду по нарисованной маске, при желании добавляет движение камеры |

## Философия простых вещей

**Сложное время требует простых вещей. И максимального контроля.**

TasyTools — крошечные программы для реальных, сверх актуальных задач.

Очистка изображений от метамусора. Более лёгкий и чистый трафик. Комфортная работа с текстурами и материалами. Лёгкие текстуры, лёгкие сцены, больше динамики и возможностей.

Облегчение видео и удобные форматы для интернета.

## Принцип

Одна программа делает одну понятную работу. Сложность остаётся внутри инструмента, а управление остаётся у человека.

FFmpeg не входит в комплект TasyTools и распространяется отдельно на собственных условиях лицензирования. См. [THIRD_PARTY.md](THIRD_PARTY.md).
